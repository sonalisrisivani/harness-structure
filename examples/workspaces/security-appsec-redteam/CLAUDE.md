# AppSec & Defensive Security Workspace

## Purpose & Scope
Authorized security analysis, vulnerability remediation, defensive hardening, and secure code review.

## Security Review Criteria
- OWASP Top 10 (Injection, Broken Auth, SSRF, XSS, etc.)
- Cryptographic hygiene (No weak ciphers, no hardcoded salts/keys)
- Input validation & strict parameter binding
- Dependency vulnerability audits

## Commands & Agents
- Run `/security-audit` for a comprehensive 6-phase security scan.
- Run `/security-check` for fast pattern-matching against known threat databases.
- Engage `@security-auditor` and `@security-patcher` to locate and remediate vulnerabilities safely.
